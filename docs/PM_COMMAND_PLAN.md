# PM Command Plan (Async Dev Pace)

## Rule
Devs can move at own pace, but each issue must close with:
1) implementation note
2) test evidence
3) short Loom/demo

## Weekly Output Cadence
- Mon: select 3-5 active issues
- Wed: blocker review + dependency unblocking
- Fri: shipped list + KPI update

## KPI Board (single source)
Track weekly:
- Match success %
- P50 time-to-match
- P50 time-to-cash (main wedge)
- Proof rejection %
- Dispute %

## Anti-Noise Filter
Reject work that does not directly improve one of:
- time-to-cash
- match success
- completion rate
- dispute reduction

If a task does not affect these, move it to backlog.
